# 子公司年度績效考核自評門戶 (Performance Appraisal Portal)

為企業量身打造的現代化績效考核導引入口網站，無縫整合 **SurveyCake** 官方表單，提供同仁直覺、兼具沉浸感與專業度的自評填答體驗。

---

## 🌟 專案亮點
- **多元填答管道**：支援原生新分頁開啟、頁內磨砂玻璃彈窗（Modal）預覽，以及行動裝置專用 QR Code 掃碼。
- **即時截止倒數**：動態計算至評核截止時間（11/30），強化儀式感。
- **四大核心維度導覽**：清楚定義「目標與成果達成」、「專業職能與創新」、「團隊協作與當責文化」、「個人成長與組織反饋」。
- **自評準備度檢查清單 (Readiness Checklist)**：互動式勾選進度條，協助同仁在填答前備妥年度量化數據與具體成果。
- **全年度時程軸與常見問題 (FAQ)**：減少同仁填答疑慮與認知負擔。
- **雙主題切換**：支援 Deep Cyber Navy（暗色）與 Clean Modern（亮色）模式切換。

---

## 🚀 部署與線上訪問
本專案為純前端靜態架構（HTML5 + Vanilla CSS + Modular JS），已配置 GitHub Actions 自動發布至 **GitHub Pages**。

---

## 🛠️ 本地開發與預覽
無需安裝複雜相依套件，直接透過任何靜態檔案伺服器即可啟動：

```bash
# 使用 Python 內建伺服器
python3 -m http.server 8080

# 於瀏覽器開啟
open http://localhost:8080
```
